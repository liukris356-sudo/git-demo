# 手机主板装配：+0.1 mm X误差与阶段化X导纳

本程序保持 `P_SAFE` 不变，从下降到后退低点开始平滑加入工件坐标系
`+0.1 mm` X误差，并把误差保持到 `P_EDGE_IN` 和最终按压阶段。机械臂仍然
只允许工件X方向产生导纳修正，另外五个方向不开放。

## 为什么改成阶段化控制

三次正常装配基线表明，越边、插入和平放本来就存在可重复的接触力：第一次
接触约 `1.6 N`，第二次插入接触约 `5.2 N`，平放过程约 `11 N`，原固定位置
终点达到约 `33--34 N`。因此不能把所有非零 `Fx` 都当成误差，否则机械臂会
对正常接触持续退让并很快达到 `0.3 mm` 修正上限。

推荐的 `PHASE_AWARE` 模式按轨迹进度读取正常受力包络：

- 正常越边接触直接放行，不启动导纳；
- 工件X受力超出当前阶段正常带并持续 `0.10 s` 后，才把超额 `Fx` 输入导纳；
- 超额受力在X方向不可纠正、或修正达到边界仍不能释放时，停止运动；
- 最终阶段不再强制压到固定P8。工件Z法向力稳定达到 `25 N` 后即认为就位；
- 合力 `30 N` 或合力矩 `1.25 Nm` 仍立即停止。

回放验证中，三组正常轨迹在纠偏窗口内均未产生超额X纠偏输入；`25 N`法向
就位条件也均早于 `30 N`合力硬保护触发。当前包络仍只来自三次同日成功数据，
属于第一版暂定参数，不是安全认证阈值。
后续应补充至少两次重新上电或重新装夹后的基线，并根据同步轨迹阶段日志更新
YAML中的包络。

## 运行顺序

1. 一个终端运行 `~/assembly.sh force-driver`。
2. 可选：另一个终端运行 `~/assembly.sh plot`。
3. 运行 `~/assembly.sh x-admit-shadow`，沿工件X轻推并确认日志中的
   `F_workobject X` 正负；同时确认最终按压方向对应工件 `+Z`。
4. 用 `~/assembly.sh guard-safe` 回到同一CSV中的 `P_SAFE`。
5. 使用假件、清空工作区并握住急停，运行 `~/assembly.sh x-admit-run`。
6. 完整输入 `ARM_PHASE_X_ADMIT` 才进入实时控制。

运行结束重点查看：

- `phase` 和轨迹进度；
- `correction X`：实际X修正；
- `Fx_ref`：工件坐标系X总受力；
- `excess Fx`：扣除该阶段正常带后的异常X受力；
- `seat force` 与 `seat=REACHED`；
- 最大合力与最大力矩。

如果 `seat force` 的正负方向与实际按压相反，只修改
`seat_force_sign`；如果X顺从方向相反，只修改 `force_to_motion_sign`。
每次只改一个符号并重新执行SHADOW。

## 保留的旧模式

`~/assembly.sh x-admit-legacy-run` 可复现原始实验：所有测得的工件 `Fx` 都直接
进入导纳模型。它不会扣除正常装配力，不推荐用于当前主板正式测试。

本程序不是安全认证功能。首次测试必须使用允许损坏的假件，并由第二个人握住
急停；任何修正方向朝障碍物加深时都应立即停止，不能依靠继续调参数解决。
